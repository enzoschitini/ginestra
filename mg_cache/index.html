I tuoi dati

Ginestra non ha un login: i progressi stanno nel browser di questo dispositivo. Qui puoi scaricarli in un file e caricarli altrove, per ritrovare serie, gemme, corone ed esami.

Scheda in incognito? Quando la chiudi i dati spariscono. Scarica il backup prima di chiuderla.

1 Scarica il backup

Un unico file JSON con tutti i dati di Ginestra di questo dispositivo. Conservalo dove vuoi: cloud, email, chiavetta.

2 Carica un backup

Scegli il file scaricato da un altro dispositivo. Prima di applicarlo vedi cosa cambierebbe.
